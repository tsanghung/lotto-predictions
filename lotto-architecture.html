🎯專案定位

一個全自動 AI 驅動的台灣彩券預測系統，結合 Python 後端統計分析、Gemini AI 深度推理、網路輿情搜尋，透過 GitHub Actions 實現零人工介入的每日自動化流程，並部署在 GitHub Pages 上。

大樂透 649 今彩 539 Gemini AI LINE 推播 GitHub Pages
🛠️技術棧
  • 後端：Python 3.10+、Pandas、NumPy、Google GenAI SDK
  • AI 模型：Gemma 4 31B（可透過環境變數切換）
  • 輿情搜尋：DDGS（DuckDuckGo Search）
  • 前端：Vue 3、Vite、Tailwind CSS v4、Chart.js
  • 自動化：GitHub Actions（3 個 Workflow）
  • 部署：GitHub Pages
  • 推播：LINE Messaging API

🕷️scraper/ — 資料爬蟲層
檔案功能狀態
scraper_core.py定義 BaseScraper 介面與 DualVerifier 雙重驗證機制（主/副來源交叉比對，確保資料 100% 正確）核心
official_scraper.py台灣彩券官方 API 爬蟲，支援 649 / 539 兩種遊戲運作中
official_sync.py官方 NTA API 自動對帳，確保歷史資料完整性運作中
update_latest.py每日抓取最新一期，更新 JSON + meta.json運作中
historical_seeder.py歷史資料種子匯入（2007年起）工具用
⚠️ DualVerifier 架構已設計完成，但第三方爬蟲來源尚未實作，目前以單點官方 API 抓取替代。
🧠analyzer/ — 分析引擎層
檔案功能
stats_engine.py統計分析核心：熱冷門號碼、遺漏值、和值分佈、奇偶比，產出 LLM Context 字串
ai_predictor.pyAI 預測主體：整合統計 + 輿情 → 呼叫 Gemini API → 解析 JSON → 離線備援
web_search.py用 DDGS 搜尋本週台灣彩券輿情，補充 LLM 推理背景
evaluator.py自動對獎 + 計算命中率 + 觸發科學歸因 + 寫入 performance.json
scientific_attribution.py命中數 < 3 時啟動 AI 歸因分析，解釋預測失準原因
gemini_config.py模型設定（預設 gemma-4-31b-it），支援環境變數切換
📊StatsEngine 分析項目
  • 全歷史頻率統計（2007年起）
  • 近 10 / 100 期熱冷門號碼
  • 遺漏值（每個號碼連續未開出期數）
  • 和值平均 / 最大 / 最小 / ±10% / ±20% 區間
  • 奇偶比（每期平均 + 累計）
  • 大小比（以號碼池一半為界）
  • 冷門池 / 統計趨勢熱門池

🔍科學歸因觸發邏輯
evaluator.py 對獎後： max_hits = 各策略中最高命中數 if max_hits < 3: → 啟動 AttributionAnalyzer（呼叫 Gemini AI） → 分析預測失準原因，寫入 attribution_report else: → "命中表現優良，無需特殊歸因"

此設計節省 API 用量，只在預測表現不佳時才觸發額外的 AI 分析。

💡關鍵設計決策
🛡️ 離線備援機制

沒有 API Key 或 Gemini 呼叫失敗時，自動切換為隨機模擬預測（_generate_mock_prediction），整個管線不會中斷，LINE 推播仍會發出（標示為模擬）。

🔄 DualVerifier 預留架構

scraper_core.py 已完整實作雙重驗證框架，但第三方爬蟲來源尚未開發，目前以單點官方 API 替代，未來可無縫接入。

📏 預測紀錄上限 50 筆

predictions.json 只保留最近 50 筆，避免 JSON 檔案過大影響 GitHub Pages 載入速度與 Actions commit 效率。

💰 API 用量節省

科學歸因只在命中數 < 3 時觸發，避免每次對獎都呼叫 Gemini，大幅降低 API 費用。

🗂️ scratch/ 目錄定位

存放大量一次性資料修補腳本（填補 2007-2026 歷史缺漏），屬於開發工具，不是正式自動化流程的一部分，不會被 Actions 執行。

🤖 模型可切換設計

透過環境變數 GEMINI_MODEL_PREDICTION 和 GEMINI_MODEL_ATTRIBUTION 可隨時切換模型，預設為 gemma-4-31b-it，Gemma 系列有特殊處理（不支援 system_instruction / JSON mode）。
